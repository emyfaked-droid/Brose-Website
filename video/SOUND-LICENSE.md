# Sound and music rights

All sounds in this project (`sfx/*.wav`, and therefore the audio of `out/ask-twice.mp4`,
`out/it-ends-with-you.mp4` and `out/i-wish-i-was-your-phone.mp4`) were generated by `scripts/make_sfx.py` from plain mathematics (sine waves,
noise, filters, reverb). No recording, sample, loop, sound library, stock music or any third-party file was
used. Regenerating from the script gives byte-identical files (checked), so the code is the only source.

- The "party music" in Ask Twice is a small drum/bass/chord loop written for this project (a common four-chord
  progression, which is not protectable).
- The audio of the reference clip you uploaded was NOT used anywhere (not in the film, not in the mix).
- The phone sounds in I Wish I Was Your Phone (notification ding, taps, buzz) are generic tones written here; they are
  not copies of any phone maker's system sounds.
- Text font: JetBrains Mono (SIL Open Font License), free for commercial use.

If you later replace sounds with real recordings, only use files that are CC0 or under the Pixabay Content License
(or Freesound with the license filter "Creative Commons 0"), and keep the source link next to the file.

This is a technical statement, not legal advice. Platforms' automatic copyright checks (e.g. Content ID) match against
known recordings; sounds generated from scratch like these are not in those databases.
